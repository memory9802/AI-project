║           爬蟲組員上傳資料檢查表                                 ║
╚═══════════════════════════════════════════════════════════════╝

每次爬完資料後,請依序檢查:

┌───────────────────────────────────────────────────────────────┐
│ ✅ 步驟 1: 驗證資料在資料庫                                      │
└───────────────────────────────────────────────────────────────┘

指令:
  docker exec outfit-mysql mysql -uroot -prootpassword outfit_db -e "
  SELECT source, COUNT(*) FROM items GROUP BY source;
  "

確認:
  [ ] 看到你爬的資料來源
  [ ] 數量正確


┌───────────────────────────────────────────────────────────────┐
│ ✅ 步驟 2: 匯出資料庫                                            │
└───────────────────────────────────────────────────────────────┘

指令:
  ./scripts/export_database.sh

  或使用一鍵助手:
  ./scripts/crawler_upload_helper.sh

確認:
  [ ] 看到 "✅ 匯出完成" 訊息
  [ ] init/outfit_db_with_data.sql 檔案存在


┌───────────────────────────────────────────────────────────────┐
│ ✅ 步驟 3: 檢查檔案                                              │
└───────────────────────────────────────────────────────────────┘

指令:
  ls -lh init/outfit_db_with_data.sql
  grep -c "INSERT INTO" init/outfit_db_with_data.sql

確認:
  [ ] 檔案大小 > 0 (不是空的)
  [ ] INSERT 語句數量 > 0


┌───────────────────────────────────────────────────────────────┐
│ ✅ 步驟 4: Git 提交                                             │
└───────────────────────────────────────────────────────────────┘

指令:
  git add init/outfit_db_with_data.sql
  git commit -m "更新資料庫:新增 XXX 個 XXX 商品"
  git push origin Crawler&Detection

確認:
  [ ] Commit message 清楚說明新增內容
  [ ] 成功 push 到 GitHub (沒有錯誤訊息)


┌───────────────────────────────────────────────────────────────┐
│ ✅ 步驟 5: 通知組員                                             │
└───────────────────────────────────────────────────────────────┘

在 Line/Discord 群組發送:

  📢 資料庫已更新!

  更新內容: 新增 XXX 個 XXX 商品

  請執行:
  1. git pull origin Crawler&Detection
  2. docker exec -i outfit-mysql mysql -uroot -prootpassword \
     outfit_db < init/outfit_db_with_data.sql

  或使用:
  ./scripts/setup_database_for_teammates.sh

確認:
  [ ] 已通知組員
  [ ] 說明了更新內容


┌───────────────────────────────────────────────────────────────┐
│ 🎉 完成!                                                       │
└───────────────────────────────────────────────────────────────┘

所有步驟完成後,組員就能看到你爬的資料了!


┌───────────────────────────────────────────────────────────────┐
│ ⚠️ 常見錯誤提醒                                                 │
└───────────────────────────────────────────────────────────────┘

❌ 只 push 程式碼,忘記匯出資料庫
   → 組員有程式碼但沒資料

❌ 只 commit CSV 檔案
   → 組員需要額外執行匯入腳本

❌ 沒有通知組員
   → 組員不知道要更新

✅ 記住:爬完 → 匯出 → Commit → Push → 通知


┌───────────────────────────────────────────────────────────────┐
│ 🚀 快速指令 (最簡單)                                            │
└───────────────────────────────────────────────────────────────┘

一鍵完成所有步驟:

  ./scripts/crawler_upload_helper.sh

這個腳本會自動:
  1. 顯示資料統計
  2. 匯出資料庫
  3. 檢查檔案
  4. Git commit & push
  5. 生成通知訊息
