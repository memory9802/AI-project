## 📁 主要檔案說明

### 1️⃣ 爬蟲階段
- **目的**: 從 UNIQLO 官網獲取商品資料
- **輸出**: 原始商品清單 (SKU, name, image_url, price)

### 2️⃣ 基礎處理階段  
- **檔案**: `init/uniqlo_175_colored_advanced.csv`
- **內容**: 
  - sku: 商品編號
  - name: 商品名稱
  - gender: 性別 (男/女/中性)
  - category: 商品類別 (T恤/襯衫/褲子等)
  - clothing_type: 服裝類型 (上衣/下身)
  - length: 長度 (長/短)
  - color: 顏色
  - image_url: 商品圖片連結
  - price: 價格

### 3️⃣ 顏色辨識階段

#### 📌 方法 1: 基礎顏色辨識
**檔案**: `advanced_color_detection.py`

**流程**:
```python
1. 下載商品圖片
   ↓
2. K-means 聚類 (3個顏色)
   ↓
3. 提取主要顏色 RGB
   ↓
4. 映射到 21 種 Pantone 色
   ↓
5. 寫入 CSV
```

**問題**:
- ❌ 背景顏色干擾
- ❌ 光線影響判斷
- ❌ 錯誤率約 64.8%

#### 📌 方法 2: 進階顏色辨識  
**改進方案**:
```python
1. 使用 rembg 移除背景
   ↓
2. 分析前景服裝
   ↓
3. RGB + HSV 雙重分析
   ↓
4. 區域性分析 (上半/下半)
   ↓
5. 加權計算主色
```

**結果**: 準確率提升但仍有限制

### 4️⃣ Gemini Vision API 階段

#### 📌 為何使用 Gemini?
1. **視覺理解能力**: 可直接"看"圖片而非只分析像素
2. **語義理解**: 理解服裝款式、剪裁、設計
3. **多欄位驗證**: 一次驗證 5 個欄位
4. **高準確率**: gender 84.5%, clothing_type 99.5%

#### 📌 實作細節

**工具**: `gemini_full_verify.py`

**API 設定**:
```python
模型: gemini-2.5-flash
限制: 15 RPM (免費版)
處理速度: ~3 秒/張
總耗時: ~10-15 分鐘 (213張)
```

**Prompt 設計**:
```
分析這張服裝商品圖片,請判斷:

1. gender (性別): 男/女
   - 觀察剪裁、領口設計
   
2. category (類別): 
   - 女裝T恤上衣、男裝襯衫、女裝褲子等
   
3. clothing_type (服裝類型): 上衣/下身
   
4. length (長度): 長/短
   - 長袖/短袖、長褲/短褲
   
5. color (顏色): 21種Pantone色
   - 黑色、白色、米色、深藍色...

請以 JSON 格式回傳
```

**批次處理流程**:
```python
for 每個商品 in CSV:
    1. 下載商品圖片
    2. 發送給 Gemini API
    3. 解析 JSON 回應
    4. 比對原始資料
    5. 記錄差異
    6. 每 5 筆自動儲存
```

**進度追蹤**:
```
[62/213] (29.1%) 商品名稱
  ⏱️  已處理: 5/152 | 耗時: 0.3分 | 預估剩餘: 8.7分
  當前: 性別=男 | 類別=男裝襯衫上衣 | ...
  Gemini: 性別=男 ✓ | 類別=男裝T恤上衣 ✗ | ...
```

### 5️⃣ 結果整合階段

#### 📌 產出檔案

**1. 完整對比版**
- `gemini_full_verification_complete.csv`
- 包含原始值、Gemini值、比對結果

**2. 差異標記版**  
- `gemini_verification_differences_only.csv`
- 使用 ❌ 標記差異欄位

**3. Gemini 純淨版**

- 只保留 Gemini 辨識結果
- 移除所有比對資訊

## 🔍 關鍵發現與洞察

### ✅ 成功項目
1. **clothing_type 辨識極準確** (99.5%)
   - Gemini 能清楚分辨上衣/下身

2. **gender 辨識良好** (84.5%)
   - 透過剪裁、版型判斷性別

3. **自動化流程建立**
   - 從爬蟲到 AI 辨識全自動

### ⚠️ 挑戰項目
1. **category 差異大** (8.0%)
   - 原因: 分類標準不同
   - 例: "男裝襯衫上衣" vs "男裝襯衫"

2. **length 判斷困難** (68.1%)
   - 原因: 圖片角度、模特兒身材
   - 平鋪圖 vs 穿著圖差異

3. **color 完全不符** (0.0%)
   - 原因: 
     * 光線影響
     * 螢幕色差
     * 主觀判斷差異
   - 需要更精確的色彩標準

### 💡 改進建議
1. **統一 category 分類標準**
   - 建立明確的類別對照表

2. **length 需要輔助資訊**
   - 加入商品描述文字分析
   - 結合尺寸規格表

3. **color 需要多模態方法**
   - 結合電腦視覺 + AI 判斷
   - 使用官方色號對照
