┌──────────────────────────────────────────────────────────────┐

## 4️⃣ Git 可以同步什麼?

```
✅ Git 會同步                        ❌ Git 不會同步
──────────────                      ───────────────
📄 .sql 檔案                        💾 資料庫實例
📄 .py 腳本                         🐳 Docker 容器
📄 .csv 資料檔                      🏃 運行中的程序
📄 .md 文件                         💿 硬碟上的資料
📂 資料夾結構                        ⚙️ 環境設定

類比:
✅ 同步「食譜」                      ❌ 不同步「做好的菜」
✅ 同步「樂譜」                      ❌ 不同步「演奏的音樂」
✅ 同步「藍圖」                      ❌ 不同步「建好的房子」
```

## 6️⃣ 完整流程圖

```
開發者 (你)                        組員
─────────                        ───────

1. 生成資料
   python3 generate_users.py
   → MySQL 有 50 個用戶

2. 匯出資料庫
   ./export_database.sh
   → 生成 outfit_db_with_data.sql

3. 提交到 Git
   git add init/outfit_db_with_data.sql
   git commit -m "更新資料庫"
   git push
                              4. 下載更新
                                 git pull

                              5. 啟動 Docker
                                 docker-compose up -d

                              6. 匯入資料庫
                                 docker exec -i outfit-mysql \
                                   mysql ... < outfit_db_with_data.sql

                              7. 驗證
                                 SELECT COUNT(*) FROM users;
                                 → 看到 50 筆資料 ✅

8. 開發 ←─────────────────→ 8. 開發
   (資料一致!)                 (資料一致!)
```

## 7️⃣ 常見誤解解答

### ❌ 誤解 1: "SQL 檔案裡面有資料"
**✅ 正確:** SQL 檔案只是文字檔,包含「指令」而非「資料」

### ❌ 誤解 2: "Git push 會同步資料庫"
**✅ 正確:** Git 只同步檔案,不同步資料庫實例

### ❌ 誤解 3: "執行 outfit_db.sql 就會有用戶資料"
**✅ 正確:** outfit_db.sql 只建立表格,需要額外執行 Python 腳本或匯入 outfit_db_with_data.sql

### ❌ 誤解 4: "Docker 容器會自動同步"
**✅ 正確:** 每台電腦的 Docker 容器是獨立的,需要手動匯入資料

```bash
# 在專案根目錄執行
./scripts/setup_database_for_teammates.sh

# 這個腳本會:
# 1. 啟動 Docker 容器

# 3. 驗證資料
# 4. 顯示測試帳號
```

### 手動操作 (理解流程)

```bash
# 步驟 1: 啟動容器
docker-compose up -d
sleep 15

# 步驟 2: 匯入資料
docker exec -i outfit-mysql mysql \
  -uroot -prootpassword outfit_db \
  < init/outfit_db_with_data.sql

# 步驟 3: 驗證
docker exec outfit-mysql mysql \
  -uroot -prootpassword outfit_db \
  -e "SELECT COUNT(*) FROM users;"
```

## 🎯 關鍵概念總結

1. **SQL 檔案 ≠ 資料庫**
   - SQL 檔案是「指令」
   - 資料庫是「執行結果」

2. **Git 只同步檔案**
   - 需要匯出資料庫成 .sql 檔案
   - 組員下載後需要匯入

3. **每台電腦都是獨立的**
   - Docker 容器互不影響
   - 需要手動同步資料

4. **兩種方式建立環境**
   - 快速: 匯入 outfit_db_with_data.sql
   - 學習: 執行 outfit_db.sql + Python 腳本
